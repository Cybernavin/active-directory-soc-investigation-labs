# Active Directory SOC Investigation Series

A hands-on Active Directory SOC lab series where I practice investigating suspicious activity using Windows logs and Splunk, from Kerberos attacks to domain compromise, lateral movement, and persistence.

## Labs

- **AD-01: Kerberos Credential Theft** — Kerberoasting and AS-REP roasting detection and investigation.
- **AD-02: Credential Dumping & Domain Compromise** — LSASS access and DCSync-related detection.
- **AD-03: Lateral Movement & Privilege Escalation** — RDP, SMB, WinRM, and remote activity detection.
- **AD-04: Persistence & Ransomware Preparation** — Scheduled tasks, Group Policy abuse, AdminSDHolder, and shadow-copy activity.

## Tools Used

Splunk Enterprise, Windows Active Directory, Windows Security logs, Sysmon, PowerShell, and Kali Linux.

Each lab includes detection searches, dashboard work, and investigation notes. My goal is to improve my SIEM skills, understand attack behavior, and build practical SOC investigation experience.

**Disclaimer:** These projects are performed in an authorized lab environment for defensive cybersecurity learning and detection engineering.
